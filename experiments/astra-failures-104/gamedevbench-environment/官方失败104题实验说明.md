# 官方 Astra 失败 104 题 × 四模型对照

本实验使用 `audit/official_failures.csv` 中 104 个任务 ID；启动脚本再次与作者发布的 `results/gpt6_astra_codex_runtime_video_high_full_333/final_results.json` 核对，要求它们恰好是 **验证失败且求解器正常结束** 的任务。四模型为 GPT-6 Astra、GPT-5.6 Sol、DeepSeek V4 Pro、Kimi K3，共 416 个模型-任务组合。与之前 12 题实验相同，每模型独立断点、默认并发 2、实时阶段反馈、Ctrl+C 可停止和续跑。

## 运行与保存位置

PowerShell 命令：

```powershell
& 'D:\ShaderAgent\re\gamedevbench-environment\Run-Official-Failures-Comparison.ps1' -Status
& 'D:\ShaderAgent\re\gamedevbench-environment\Run-Official-Failures-Comparison.ps1' -Parallel 2
```

模型在运行时会产生费用。要先试一个任务，可用 `-MaxTasks 1`；要中断现有批次，可用 `-Stop`，或在运行窗口按 Ctrl+C。再次运行同一个命令可续跑。`-Status` 不调用模型。Windows 空闲睡眠在运行期间阻止，显示器仍可熄屏。

本地汇总目录：`batch_runs/official_failures_comparison/`。

- `comparison.csv`：逐题判分、求解器状态、成本、耗时、错误位置、轨迹和项目产物路径。未完成任务也保留为待运行行。
- `review_queue.csv`：将作者 Astra 的首个失败消息和本地每模型结果并列，区分模型正常完成、求解器中断、同一失败点或不同失败点；`false_negative_verdict` 默认 `not_reviewed`，不能自动把模型分数差异当成验证器假阴性。
- `summary.json`：进度和模型信息。
- 各模型 `batch_runs/<模型>_official_failures_104/state.json`、`results.csv`、`workers/`：续跑断点和控制台日志。
- 原版项目 `results/<run_name>/task_<task>.json` 和 `tasks/test_result/<run_name>/<task_run>/agent_trajectory.log`：官方逐题判分、模型可见的回复/工具轨迹及项目产物。

**原始数据只保存在本机。** `official_failures.csv` 的 `instruction` 列和 `agent_trajectory.log` 可能包含模型收到的任务文字，不应直接上传到已公开的 GitHub 仓库。统计和审计结论若要公开，应先生成不含 prompt 的副本并复核。

## 公平性边界

原作者 Astra 基线：Codex agent、GPT-6 Astra、Godot 4.4.1、high effort、runtime video 开启、strict confinement、MCP 关闭、display 开启、并发 16。此次沿用原项目的任务 ZIP、验证器、Godot 4.4.1、high、runtime video、strict、MCP 关闭和 display 开启；四模型均使用此前对照实验的 OpenCode/Shubiaobiao 路径，默认并发 2、600 秒求解器超时、API 错误 300 秒间隔最多重试 3 次。**由于 agent、供应商路径、并发和部分沙箱组件不同，不是作者 Astra 原运行的逐字复现。** 这些差异应随结果报告一起保留，不能把不同代理的分数差异直接解释为模型能力差异。

传给求解器的是原项目常规任务输入。`benchmark_runner.py` 构建沙箱时过滤 `test.gd`、测试场景和完整 `task_config.json`，只保留 `instruction` 字段；作者失败消息、参考实现和 `review_queue.csv` 不进入求解器工作目录。验证器只在模型求解之后加载。启动前应保持原版 `benchmark_runner.py` 和任务 ZIP 不变。

## 假阴性复核口径

优先从 **求解器正常结束但官方验证失败** 的记录入手。逐题检查首个失败断言、模型保存的资源/场景和运行时有效值；必要时在产物副本上执行 Godot 探针或行为/画面复核。把“已证实报错点错误”“高可信候选”“结构契约争议”“模型实现缺失”“求解未完成”分开记录。保持官方原始判分和产物不变，人工结论另存。其他模型通过同一题只说明可能存在不同实现路径，**不直接证明 Astra 的原失败是假阴性**。
